# Umed Harwani — Personal Portfolio

🌐 **Live Website:** https://umedharwani-cmyk.github.io/umed-portfolio/

A personal portfolio website built from scratch to showcase my journey as a Computer Science student and beginner frontend developer.

This is my first web development project, created to strengthen my fundamentals in HTML, CSS, and JavaScript while learning how a real responsive website is structured, styled, and deployed.

## ✨ Features

- Responsive design for desktop and mobile
- Neon-inspired visual design
- Animated floating elements
- Canvas-based particle background
- Smooth scrolling and scroll reveal animations
- Responsive mobile navigation
- Accessibility-focused focus states
- `prefers-reduced-motion` support
- Performance-conscious canvas animation
- Resume download
- Links to GitHub and LinkedIn

## 🛠️ Technologies Used

- **HTML5** — Semantic website structure
- **CSS3** — Responsive layouts, animations, styling, and visual effects
- **JavaScript** — Navigation, scroll interactions, canvas animation, and dynamic elements
- **Canvas API** — Animated particle background
- **Git & GitHub** — Version control and project hosting
- **GitHub Pages** — Website deployment
